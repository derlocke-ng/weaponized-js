# gunfile
- based on gunjs
- plain js or ts, no npm!
- use latest lts versions of software
- performance should be always good: KISS
what it does:
creates links for streaming files over public gunjs nodes in a webui:
workflow:
visit website -> enter code/link or upload file:
upload file -> encrypt it -> create code/link -> when link/code is opened, data will be streamed over gunjs
